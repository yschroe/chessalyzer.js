---
title: Trackers
description: Collect statistics during analysis — per move or per game.
---

**Trackers** define what Chessalyzer measures. Call a tracker **factory** to create an **instance**, pass that instance to `analyzePGN`, then read accumulated **state** from the same handle.

| Concept      | What it is                                                                                 |
| ------------ | ------------------------------------------------------------------------------------------ |
| **Factory**  | Callable from `defineMoveTracker` / `defineGameTracker` (or a built-in like `tileTracker`) |
| **Instance** | Handle returned by the factory — what you pass to `analyzePGN`                             |
| **State**    | Plain accumulated data — what you read from `instance.state` after analysis                |

There are two kinds:

| Kind             | Factory             | Receives                  | Example                       |
| ---------------- | ------------------- | ------------------------- | ----------------------------- |
| **Move tracker** | `defineMoveTracker` | Per-move board/actions    | `tileTracker`, `pieceTracker` |
| **Game tracker** | `defineGameTracker` | Headers + result per game | `gameTracker`                 |

Move trackers need `replay: 'actions'`. Game trackers only need headers (set `headers: true` or use `'auto'`).

## Usage

```javascript
import { analyzePGN } from 'chessalyzer';
import { tileTracker, gameTracker } from 'chessalyzer/trackers';

const tiles = tileTracker();
const games = gameTracker();

await analyzePGN('<pathToPgnFile>', {
    trackers: [tiles, games],
});

console.log(tiles.state.movesTotal, games.state.games);
```

Each call to a factory returns a fresh instance with its own `.state`. Use distinct instances when you need separate cohorts in a multi-run analysis.

- [Built-in trackers](/docs/trackers/built-in) — `gameTracker`, `pieceTracker`, `tileTracker`
- [Custom trackers](/docs/trackers/custom) — factories for your own stats
