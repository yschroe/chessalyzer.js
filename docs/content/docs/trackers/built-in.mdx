---
title: Built-in trackers
description: gameTracker, pieceTracker, and tileTracker.
---

Chessalyzer ships three built-in tracker factories (`gameTracker`, `pieceTracker`, `tileTracker`). Call them to create instances, pass those to `analyzePGN`, then read **`instance.state`**.

```javascript
import { analyzePGN } from 'chessalyzer';
import { tileTracker } from 'chessalyzer/trackers';

const tiles = tileTracker();

await analyzePGN('<pathToPgnFile>', { trackers: [tiles] });
console.log(tiles.state.movesTotal);
```

## gameTracker

Per-game statistics from headers and results.

| Field       | Description                             |
| ----------- | --------------------------------------- |
| `results`   | Counts of white wins, draws, black wins |
| `eco`       | ECO code counts (e.g. `'A00'`)          |
| `gameCount` | Number of games processed               |

## pieceTracker

Tracks captures between pieces.

| Field | Description                                                                          |
| ----- | ------------------------------------------------------------------------------------ |
| `b`   | Black pieces — how often each black piece captured each white piece (e.g. `b.Pa.Qd`) |
| `w`   | Same for white pieces                                                                |

## tileTracker

Tracks what happens on each square of the board.

| Field        | Description                                                     |
| ------------ | --------------------------------------------------------------- |
| `tiles[][]`  | Per-square stats for each piece (`b`/`w` → `total` / `byPiece`) |
| `movesTotal` | Total moves processed                                           |

Each tile has two color buckets (`b`, `w`). Each bucket has a `total` stats object plus per-piece stats under `byPiece` (`Pa`, `Ra`, etc.):

- `movedTo` — how often the piece moved to this square
- `occupiedFor` — half-moves the piece was on this square
- `captures` — captures made on this square
- `losses` — times the piece was lost on this square

Use `tileAt(state.tiles, square)` to read a square by name. Then take `total` for the combined stats of one side (e.g. `cell.b.total.occupiedFor`), or `byPiece` for a single piece (e.g. `cell.b.byPiece.Pa.occupiedFor`):

```javascript
import { tileAt } from 'chessalyzer/trackers';

const cell = tileAt(tiles.state.tiles, 'g8');
console.log(cell?.b.total.occupiedFor, cell?.b.byPiece.Pa.occupiedFor);
```

`tileTracker` and `pieceTracker` support [heatmap generation](/docs/heatmaps) — pass state and a preset function to `generateHeatmap(tiles.state, TileHeatmapPresets.TILE_OCC_ALL)`.
