---
title: Built-in trackers
description: GameTracker, PieceTracker, and TileTracker.
---

Chessalyzer ships three built-in trackers (`GameTracker`, `PieceTracker`, `TileTracker` — pass the definition itself, no `new`). Stats live on **`result.runs[n].trackers[m].state`** after `analyzePGN` returns.

```javascript
import { analyzePGN } from 'chessalyzer';
import { TileTracker } from 'chessalyzer/trackers';

const result = await analyzePGN('<pathToPgnFile>', { trackers: [TileTracker] });
const state = result.runs[0].trackers[0].state;
```

## GameTracker

Per-game statistics from headers and results.

| Field     | Description                             |
| --------- | --------------------------------------- |
| `results` | Counts of white wins, draws, black wins |
| `ECO`     | ECO code counts (e.g. `'A00'`)          |
| `games`   | Number of games processed               |

## PieceTracker

Tracks captures between pieces.

| Field | Description                                                                          |
| ----- | ------------------------------------------------------------------------------------ |
| `b`   | Black pieces — how often each black piece captured each white piece (e.g. `b.Pa.Qd`) |
| `w`   | Same for white pieces                                                                |

## TileTracker

Tracks what happens on each square of the board.

| Field        | Description                                                     |
| ------------ | --------------------------------------------------------------- |
| `tiles[][]`  | Per-square stats for each piece (`b`/`w` → `total` / `byPiece`) |
| `movesTotal` | Total moves processed                                           |

Each tile has two color buckets (`b`, `w`). Each bucket has a `total` stats object plus per-piece stats under `byPiece` (`Pa`, `Ra`, etc.):

- `movedTo` — how often the piece moved to this square
- `wasOn` — half-moves the piece was on this square
- `capturedOn` — captures made on this square
- `wasCapturedOn` — times the piece was captured on this square

Use `total` for combined stats of one side on a square (e.g. `state.tiles[0][6].b.total.wasOn`), or `byPiece` for a single piece (e.g. `state.tiles[0][6].b.byPiece.Pa.wasOn`).

`TileTracker` and `PieceTracker` support [heatmap generation](/docs/heatmaps) — pass state and the matching preset map to `generateHeatmap(state, presets, { analysis })`.
