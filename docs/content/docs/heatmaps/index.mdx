---
title: Heatmaps
description: Turn tracker data into per-square values for preview or visualization.
---

After running `analyzePGN`, tracker **state** holds the raw statistics. **Heatmaps** map that state to a value for each square on the board.

```javascript
import { analyzePGN, printHeatmap } from 'chessalyzer';
import { TileTracker } from 'chessalyzer/trackers';

const tileTracker = new TileTracker();
const result = await analyzePGN('<pathToPgnFile>', { trackers: [tileTracker] });

const { state } = result.trackers[0];
const heatmapData = tileTracker.generateHeatmap(state, { analysis: 'TILE_OCC_ALL' });
printHeatmap(heatmapData);
```

## What you get

`generateHeatmap` returns data you can pass to `printHeatmap` for a quick terminal preview, or feed into your own visualization library. Chessalyzer provides the **data**, not chart components.

## Options

- **[Presets](/docs/heatmaps/presets)** — built-in short names like `'TILE_OCC_ALL'` for common views
- **[Custom functions](/docs/heatmaps/custom-functions)** — write your own per-square calculation
- **[Comparing analyses](/docs/comparing-analyses)** — `generateComparisonHeatmap(state, otherState, { analysis })` for side-by-side cohorts

`TileTracker` and `PieceTracker` expose `generateHeatmap(state, options)` and `generateComparisonHeatmap(state, otherState, options)` helpers.
