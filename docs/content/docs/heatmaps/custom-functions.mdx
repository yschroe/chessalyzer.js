---
title: Custom heatmap functions
description: Write your own per-square calculation for generateHeatmap.
---

Pass any function as the `analysis` argument to `generateHeatmap(state, analysis)`. The function is called for every square on the board.

```javascript
import { generateHeatmap, tileAt } from 'chessalyzer/trackers';

// after analyzePGN — read state from your tracker instance
const heatmapData = generateHeatmap(tiles.state, ({ data, square }) => {
    const cell = tileAt(data.tiles, square);
    if (!cell) return 0;
    return (cell.w.total.occupiedFor * 100) / data.movesTotal;
});
```

Capture extra values from the outer scope when you need them (e.g. a piece of interest or a precomputed average) — no special options field is required. Built-in scoped presets use the same pattern as factories:

```javascript
const queen = { color: 'w', name: 'Qd' };

const heatmapData = generateHeatmap(tiles.state, ({ data, square }) => {
    const cell = tileAt(data.tiles, square);
    if (!cell) return 0;
    return cell[queen.color].byPiece[queen.name].movedTo;
});
```

## Analysis function arguments

Your function receives a single object with three properties:

| Property        | Type                      | Description                                                          |
| --------------- | ------------------------- | -------------------------------------------------------------------- |
| `data`          | your tracker state        | State passed to `generateHeatmap` (e.g. `TileTrackerState`)          |
| `square`        | `Square`                  | Square being calculated, e.g. `'a2'`                                 |
| `startingPiece` | `HeatmapPieceRef \| null` | Piece that starts the game on `square`, or `null` if it starts empty |

Use `square` when each cell means a **board location**, and `startingPiece` when each cell means a **piece identity** (how `PIECE_CAPTURED` and `TILE_OCC_BY_PIECE` work):

```typescript
import type { HeatmapFn, HeatmapPieceRef } from 'chessalyzer/trackers';

// HeatmapPieceRef: { color: 'b' | 'w'; name: StartingPieceName }

const byPieceIdentity: HeatmapFn = ({ data, startingPiece }) => {
    if (!startingPiece) return 0;
    return lookUp(data, startingPiece.color, startingPiece.name);
};
```

You can also type the whole function with `HeatmapFn<YourState>` to get full inference on `data`.

See [Presets](/docs/heatmaps/presets) for built-in functions you can study or reuse.
