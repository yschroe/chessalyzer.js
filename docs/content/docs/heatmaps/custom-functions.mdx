---
title: Custom heatmap functions
description: Write your own per-square calculation for generateHeatmap.
---

Pass any function as the `analysis` argument to `generateHeatmap(state, analysis)`. The function is called for every square on the board.

```javascript
import { generateHeatmap } from 'chessalyzer/trackers';
import { squareToCoords } from 'chessalyzer/replay';

// after analyzePGN — read state from your tracker instance
const heatmapData = generateHeatmap(tiles.state, ({ data, loopSquare }) => {
    const [row, col] = squareToCoords(loopSquare.square);
    const val = data.tiles[row][col].w.total.wasOn;
    return (val * 100) / data.movesTotal;
});
```

Capture extra values from the outer scope when you need them (e.g. a piece of interest or a precomputed average) — no special options field is required. Built-in scoped presets use the same pattern as factories:

```javascript
const queen = { color: 'w', name: 'Qd' };

const heatmapData = generateHeatmap(tiles.state, ({ data, loopSquare }) => {
    const cell = data.tiles[/* … */];
    return cell[queen.color].byPiece[queen.name].movedTo;
});
```

## Analysis function arguments

| Property     | Description                                                         |
| ------------ | ------------------------------------------------------------------- |
| `data`       | Tracker state passed to `generateHeatmap` (e.g. `TileTrackerState`) |
| `loopSquare` | Info about the square being calculated                              |

### `loopSquare` shape

```typescript
import type { Square } from 'chessalyzer/replay';

interface SquareData {
    square: Square; // e.g. 'a2'
    piece: {
        name: string; // e.g. 'Pa'
        color: 'b' | 'w';
    } | null;
}
```

See [Presets](/docs/heatmaps/presets) for built-in functions you can study or reuse.
