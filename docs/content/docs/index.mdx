chessalyzer is a JavaScript library for working through large PGN databases and collecting exactly the statistics you care about — move by move, or game by game.

Give it a file, pick a few **trackers**, and it handles the heavy lifting: reading the PGN, replaying moves on an internal board, and aggregating results. You stay in control of what gets measured, which keeps things fast even on big exports.

## What it's good at

- **Batch analysis** — process thousands or millions of games without loading everything into memory at once.
- **Modular stats** — track only what you need (results, captures, tile occupation, or your own metrics).
- **Heatmaps** — turn tracker data into square-by-square values for terminal preview or your own visualizations.
- **Throughput** — designed for multi-core machines; multithreaded by default.

If you just want parsed games without board replay, the [`pgn-parser`](/docs/pgn-parser) module has you covered too.
