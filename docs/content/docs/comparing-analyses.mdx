---
title: Comparing analyses
description: Run multiple filtered cohorts and compare their heatmaps.
---

Use the `runs` option to analyze different game subsets in one pass — each run gets its own tracker definitions and optional filter.

This example compares tile occupation for high-rated vs low-rated white players (1000 games each):

```javascript
import { analyzePGN } from 'chessalyzer';
import { TileTracker } from 'chessalyzer/trackers';
import { squareToCoords } from 'chessalyzer/replay';

const tileT1 = new TileTracker();
const tileT2 = new TileTracker();

const result = await analyzePGN('<pathToPgnFile>', {
    workers: false,
    headers: true,
    runs: [
        {
            trackers: [tileT1],
            filter: (game) => Number(game.headers?.WhiteElo) > 2000,
            maxGames: 1000,
        },
        {
            trackers: [tileT2],
            filter: (game) => Number(game.headers?.WhiteElo) < 1200,
            maxGames: 1000,
        },
    ],
});

const state1 = result.runs[0].trackers[0].state;
const state2 = result.runs[1].trackers[0].state;

const compareFunc = ({ data, loopSquare }) => {
    const [row, col] = squareToCoords(loopSquare.square);
    const val = data.tiles[row][col].w.wasOn;
    return (val * 100) / data.movesTotal;
};

const heatmapData = tileT1.generateComparisonHeatmap(state1, state2, { analysis: compareFunc });
```

`generateComparisonHeatmap` builds two heatmaps from the same analysis function and returns per-cell percentage differences.

Because filters require the main thread, pass `workers: false`. See [Filters](/docs/filters) and [Heatmaps](/docs/heatmaps).
