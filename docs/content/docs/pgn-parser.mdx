---
title: PGN parser
description: Parse PGN files without running the full analysis pipeline.
---

The `chessalyzer.js/pgn` module gives you parsed games without board replay — useful when you only need headers and move strings.

```javascript
import { parsePGN, streamParsePGN } from 'chessalyzer.js/pgn';

// Load all games into memory
const games = await parsePGN('<pathToPgnFile>', { headers: true, maxGames: 100 });
// games[0].moves[i].san — mainline SAN strings

// Stream one game at a time (better for huge files)
for await (const game of streamParsePGN('<pathToPgnFile>', { headers: true })) {
    console.log(game.headers?.White, game.headers?.Black, game.moves.length);
}
```

## Options

| Option     | Description                                          |
| ---------- | ---------------------------------------------------- |
| `headers`  | Parse tag pairs (`White`, `Black`, `WhiteElo`, etc.) |
| `maxGames` | Stop after N games                                   |

## vs `analyzePGN`

|              | `parsePGN` / `streamParsePGN` | `analyzePGN`       |
| ------------ | ----------------------------- | ------------------ |
| Board replay | No                            | Yes (configurable) |
| Trackers     | No                            | Yes                |
| Speed        | Fastest for raw game data     | Full pipeline      |

If you need legal move replay or tracker stats, use `analyzePGN`. If you just want structured game data, use the parser module. See [How it works](/docs/how-it-works) for the full pipeline.
