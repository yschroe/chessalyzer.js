A typical workflow: create a tracker instance, run `analyzePGN`, read state from the same handle, then turn it into a heatmap.

This example tracks **tile occupation** — how often each square had a piece on it — using the built-in `tileTracker`:

```javascript
import { analyzePGN, printHeatmap } from 'chessalyzer';
import { generateHeatmap, TileHeatmapPresets, tileTracker } from 'chessalyzer/trackers';

const tiles = tileTracker();

const result = await analyzePGN('<pathToPgnFile>', { trackers: [tiles] });

console.log(result.gameCount, result.moveCount, result.movesPerSecond);

const heatmapData = generateHeatmap(tiles.state, TileHeatmapPresets.TILE_OCC_ALL);

printHeatmap(heatmapData);
```

## What happened

1. **`tileTracker()`** created a tracker instance with typed `.state`.
2. **`analyzePGN`** read the PGN, replayed each game, and accumulated stats into that instance.
3. **`tiles.state`** holds the tile stats after analysis returns.
4. **`generateHeatmap(tiles.state, TileHeatmapPresets.TILE_OCC_ALL)`** turned that state into a per-square value map using a built-in preset.
5. **`printHeatmap`** rendered a quick color preview in the terminal (if your terminal supports colors).

Inspect `tiles.state.tiles` directly, or generate other heatmap presets. See [Trackers](/docs/trackers) and [Heatmaps](/docs/heatmaps).
